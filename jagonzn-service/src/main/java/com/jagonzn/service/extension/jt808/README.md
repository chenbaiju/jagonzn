### 门磁上报与命令结果关联

负责人已明确开锁任务按门磁判据闭环。新增显式开关`jagonzn.jt808.door-contact-confirmation-enabled` / `JAGONZN_JT808_DOOR_CONTACT_CONFIRMATION_ENABLED`，默认false保留原行为。开启时，门磁目标状态的达成可通过现有`DeviceCommandAccessReplyPort.applyAuthenticated`提交SUCCESS；不等待缺失的`0x0001`，不伪造协议ACK，也不回改任何旧超时结果。开锁任务在对应OPEN报告时成功，后继CLOSED只作为该次开锁后关门的状态日志关联，不生成关锁指令或第二次成功。

当前严格模式要求：已认证的同一连接先有新鲜主动门磁基线（接收后30秒内，报告时间与原接收时间相差最多5秒）；开锁前基线为闭合，关锁前基线为分离；每台设备最多一条物理控制在途。发送前将会话随机标识、原凭据代际、基线摘要/流水和发送时间随意图原子落盘。缺基线、已处目标状态、另一控制在途或未核对的UNKNOWN均不发送。此门禁是扩展关联模式的条件，不能把单有TCP鉴权误当作已有新鲜门磁基线。

完成证据必须是`0x0200`主动报告，发生及原接收时间在当前命令有效期窗口内，流水递增、状态由相反值转到目标值，开锁原因为1且门磁分离，关锁原因为2且门磁贴合。设备时间只有秒精度，发生时间与发送时间比较保留原值并容许同一秒的量化差异，不改写设备时刻。查询`0x0201`、旧/重复/逆序报文、过期、重连、凭据代际变更及未知写入均不能完成原命令；密码、刷卡、报警或定时等不匹配的门磁跃迁会使该次关联失效，不冒认控制成功。
