# JADR-0014：Console 完整复制、共享合同直引与上游差异合并

- 状态：已接受（2026-10-10）；本机实施与验证以[专题方案](../console-reuse-and-evolution.md)为准。
- 依据：负责人确认先完整复用 ThingsCloud Console，品牌改为 jagonzn、后端使用 jagonzn-service，后续继续接纳上游改进；前端目录为 jagonzn-console，与 cloud 无关；共享合同包直接引用，不复制。

## 决策

完整复制上游前端受版本控制的源码、测试、文档、配置和资源。保留原菜单，精简为首页/设备/告警/设置的方案暂不实施。设备专属页面和权限随设备接入另行设计。

jagonzn-console 直接引用现有 `../../things-cloud-client-contracts`，不另建副本。此构建依赖要求配套目录和版本，但不要求 ThingsCloud 后端进程运行。运行请求连接 jagonzn-service；jagonzn-cloud 保持独立业务后端职责。

通过固定上游提交与三方合并接纳前端更新，保留本地品牌、代理及后续定制。冲突、共享包变化和新 API 依赖须核验，不做自动覆盖或无验证上线。原 MIT 版权、协议标识和历史证据保留。

## 取舍与边界

当前不从零重写公共页面，也不拆共享 UI 框架，以控制开发量；直接引用共享包减少副本，但单独克隆 jagonzn 时必须另行取得该依赖。全量复制不证明 service 已支持每个页面对应的接口，构建与单元通过不代替真实业务验收。

本决定取代此前暂停全量复制、仅建设静态页的阶段实施选择；保留旧静态页源码及测试记录，不改写原结论。不改变 JADR-0007 的后端数据权威和统一前端边界。
