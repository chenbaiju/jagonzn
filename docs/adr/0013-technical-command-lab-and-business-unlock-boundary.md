# JADR-0013：本机技术命令验证与未来业务开锁入口分离

- 状态：已接受（2026-09-28）；仅冻结边界，未实现 cloud 业务命令。
- 依据：[主架构 §7](../jagonzn-system-architecture.md)、[JADR-0007](0007-unified-console-and-backend-boundary.md)、[JADR-0011](0011-private-cloud-delivery-scope-rotation-and-recovery.md)、[平台公开命令合同](../../../things-cloud/things-cloud-integration/src/main/java/com/things/cloud/integration/api/OpenCommandController.java)。

## 四维审计

| 维度 | 结论 |
| --- | --- |
| 事实依据 | service 现有受控技术命令 API 和项目范围公开 API Key 命令入口；后者有 `device:control`、幂等键和按键恢复，但请求没有业务操作失效时间。平台 `command.completed` 只表示持久终态事实；cloud 当前只有私有事件 Inbox，没有人员权限、场所或业务操作表。 |
| 逻辑连贯性 | API 受理 202、Broker 派发、设备 ACK、设备报告成功和物理锁状态是不同事实。cloud 持有技术 Key 不能代替操作者的业务授权；客户端只在发送前检查过期，不能阻止已受理命令在重试/恢复后迟到执行。 |
| 信息缺口 | 首台锁的型号/固件、命令 ID 去重及结果查询能力、失效时间如何在 service 派发前执行、cloud 操作者身份/撤权/时区、项目与锁关系及跨服务审计字段尚未定稿。 |
| 观点区分 | 现有接口与字段缺口是代码事实；瞬时开锁未知结果不可无条件重发是主架构规定；先完成无害技术命令实验、业务开锁另经服务端有效期和权限合同是本 ADR 的建议并获本轮连续推进授权。 |

## 决策

本机内网实验先走 **service 受控设备运维身份 → 已支持的技术命令 → 模拟设备最终回复 → service 持久 `command.completed` → cloud 独立 Inbox**。每一跳记录同一项目、设备、命令 ID、来源事件 ID、状态及重投结果；cloud 接收 200 只表示 Inbox 持久，不表述业务处理或物理开锁。实验命令须是无害且已定义的技术命令，不使用真实门锁开锁动作。没有 cloud 时 service 仍可独立执行技术命令。

未来 cloud 业务发起必须先有自己数据库中的操作者、锁/场所、允许时段与撤权事实，原子保存业务操作 ID、部署/项目/设备、命令类型与参数摘要、授权决策版本、签发和排他失效时刻。service 必须独立验证服务身份、部署/项目/设备范围、参数、幂等与当前授权状态，并在实际派发和每次重试前拒绝已失效的瞬时动作；同业务键异内容拒绝，结果未知按原键查询，不能自动生成新动作。cloud 仅把相同命令 ID 的终态与已保存业务操作关联；不能从 ACK 或 socket 写成功推断锁已打开。浏览器不得持有服务间 Key 或直连内核受信入口。

现有公开 API Key 命令入口可用于明确授权的**技术运维实验**，因为它有项目控制许可、幂等与恢复；它当前没有每次业务操作的服务端失效字段，因此不获准直接承载物理开锁业务。业务桥接实施前，ThingsCloud 须评审原命令内核的失效/恢复约束和受控服务间接口，jagonzn 只能通过正式能力使用，不能绕开平台表或 `submitTrusted` 入口。首台真实锁协议若不能证明命令去重/结果查询，单次执行保证须按设备能力收窄。

## 备选与后续验收

- **只由 cloud 在发请求前检查时间，然后调用现有公开命令 API**：无法阻止 service 已受理命令在网络恢复后迟到派发，暂不用于瞬时开锁。
- **直接开放 `submitTrusted` 给 cloud**：该端口明确依赖上层先完成身份和项目控制证明，直接调用会绕过授权，不采用。
- **服务端带有效期的受控桥接**：作为业务开锁方向；具体端口、存储与字段须在首台设备和 cloud 权限模型明确后经平台评审。

`G3-SHC-JAG-TECH-COMMAND-LAB-1` 的回执应包含同固定候选、service API 受理、模拟设备 ACK/最终回复、cloud Inbox、断线重投和不匹配事件拒绝。它只能关闭技术实验。人员开锁端到端验收仍需独立业务模型、服务端有效期、身份、真实设备协议和结果语义回执。

2026-09-28 后续状态：上述技术实验已在本机固定候选完成，见[动态回执](../../../docs/reuse-entry/audits/G3-SHC-JAG-TECH-COMMAND-LAB-1-2026-09-28.md)。回执使用模拟 MQTT 设备与临时低磁盘阈值，不能推出物理锁、正常容量或正式客户放行。
