# jagonzn 实施债务与测试阻塞

更新日期：2026-09-30。记录已确认的本项目实现缺口、交付材料和验证前置；不改变平台合同，不将未验项标为通过。详细命令、候选摘要及结果见[本机专项继续验证](../../docs/reuse-entry/THINGS_CLOUD_LOCAL_CONTINUATION_20260930.md)。

## 001：Windows 原生离线授权导入权限兼容

- 依据：离线导入命令文档明确当前仅支持 POSIX；JADR-0006 的申请身份已支持所有者 ACL，两者是不同入口。
- 实测：实际 service 候选 SHA-256 `c7998480716a51c794d8377a4a1de353f29dbc08f4be034420d7e740a3496640`，原生 NTFS 身份 9 项通过；`SignedGrantImportCommand.readGrant` 及实际 JAR CLI 均在 `Files.getPosixFilePermissions` 抛出 `UnsupportedOperationException`。
- 归属：jagonzn 自身 CLI 的兼容实现，不登记为 ThingsCloud 平台已交付修复。
- 状态：缺口已复现，待明确导入文件的 Windows 权限合同并实现；不能删除权限检查或借 POSIX 成功宣称 Windows 已支持。
- 关闭条件：原生 NTFS 合法受限文件可读取/导入，非所有者 ACL、链接、错误文件、篡改及错误信任拒绝均有复验回执；正式签名资格独立验收。

- 依据：2026-09-28 原私有交付回执记录 service SHA-256 `1c7681edb46e082a8232d00a12ba78009638bf54a756490c031c589b055334e9`、cloud `e69c08e5cc9b3e87c2e1c35fb97a780d5d39a00d4903ff3ef2b5ccdf7776173b`。
- 实测：检索仓库及忽略目录、仓外测试目录、桌面/下载、Maven 缓存和现有 LAN 私有卷均未找到摘要匹配原件；现有 rc4、SNAPSHOT 和 Git bundle 不能替代。
- 归属：交付材料；需要原同字节制品或受认可的获取位置，未指定远程仓库时不假定可下载。
- 状态：`UNAVAILABLE_INPUT`，同候选正常容量/授权/恢复复验待材料。
- 关闭条件：两份原件摘要核对通过，并在正常容量条件下完成其独立复验；重建新候选须另登记身份与范围。
