## 范围与四维依据

- 事实依据：负责人最新指令暂停原 Console/共享包复制，改为仅创建无需登录、没有操作的测试界面；既有 JADR-0007 的正式管理合同保持独立。

- 观点区分：免登录/无操作来自负责人要求；Vue + Vite 和回环端口 13006 是本轮实现选择，端口沿用既有本机 Console 预留值。
